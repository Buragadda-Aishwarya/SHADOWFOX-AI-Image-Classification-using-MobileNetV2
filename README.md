# AI Image Classifier (MobileNetV2)
A lightweight image recognition tool built with Python and TensorFlow.

## Overview
This project uses the MobileNetV2 architecture to classify images into 1,000 categories based on the ImageNet dataset. It is optimized for speed and efficiency.

## Features
- Top-3 prediction labels with confidence scores.
- Automated image preprocessing pipeline.
- Visual output using Matplotlib.

## Tech Stack
- Python, TensorFlow/Keras, NumPy, Matplotlib.
